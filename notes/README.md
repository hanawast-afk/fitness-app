# notes: 壁打ち・相談の記録

結論だけでなく「なぜそうしたか」を残す場所。次のAIが同じ説明を聞かずに、細かい判断まで引き継げるようにする。

- ファイル名: `YYYY-MM-DD-テーマ.md`（例: `2026-11-19-種目の追加.md`）
- 書くこと: 話した背景 / こだわり・好み / 検討して却下した案とその理由 / 未決のこと
- Satoshiさんの音声入力は、言い直しや脱線を整えて要点だけを書く（逐語録は不要）。
- 決まったことは decisions.md にも1行で追記し、このノートのファイル名を添える。
- 機密は書かない（トークン・ログイン情報）。

AIに「今の話を notes に残して」と言えば、この形式で書く。
